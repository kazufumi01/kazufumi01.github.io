縦軸はdB（VUは「サイン波ピーク換算のdBFS」、LUFSはそのままの数値）。同じ瞬間に各メーターがどれだけ遅れ、どれだけ低く読むかを線の形で比べてください。

Experiments

ボタンで信号と設定を切り替えます。期待値は 0 VU = −18 dBFS、入力ゲイン 0 dB のときの数値です。

Reference

このアプリでの実装値と、実務で押さえておきたい使いどころ。

VU IEC 60268-17 / ANSI C16.5

全波整流した信号の平均に、針の慣性（2次系）をかけたメーター。立ち上がりは遅く、人が感じる「音の太さ」に近い動きをします。目盛りはサイン波で実効値に合うよう校正されています。

立ち上がり
300 ms で 99%、オーバーシュート 1〜1.5%
実装
ζ = 0.80、ωn = 13.2 rad/s（実測 0.30 s / +1.4%）
基準
0 VU = +4 dBu（機材）。DAWでは −18 dBFS（EBU R68）や −20 dBFS（SMPTE）に置くのが一般的
目盛り
電圧に比例（−20〜+3 VU）。下側は潰れて読めない
使いどころ：アナログモデリング系（1176、LA-2A、テープ、コンソール）への入力レベル合わせ。設計上の「おいしい」動作点が 0 VU 付近にあるため、VUで 0 前後を振れるように前段ゲインを決めると、歪み方がモデルの想定どおりになります。

Sample Peak dBFS

サンプル値の絶対値の最大。アタックは即時で、1サンプルのピークも逃しません。ただし「サンプルとサンプルの間」は見ていません。

アタック
0 ms（ブロック内最大値）
リリース
12 dB/s（表示用）、ホールド 1.5 s
0 dBFS
固定小数点で表せる最大値。32-bit float内部では超えても壊れないが、書き出しで飽和
使いどころ：デジタルクリップの監視、トラックのヘッドルーム確認。音量感とはほぼ無関係なので、フェーダーバランスの判断には使わない。

True Peak ITU-R BS.1770 Annex 2 · dBTP

4倍以上にオーバーサンプリングして、D/A後に再構成される波形のピークを推定します。リミッターでサンプルを −0.1 dBFS に揃えても、再構成波形は 0 dBFS を超えることがあります。

実装
4× ポリフェーズFIR（48 tap, Blackman-Harris窓）
誤差
fs/4・45°テストで約 −0.2 dB（規格の許容内の目安）
配信の目安
−1 dBTP 以下。非可逆圧縮のデコードで更にピークが増えるため
使いどころ：マスターの最終段。リミッターのTrue Peakモードやシーリングを決める根拠。ラウドなマスターほどTPとサンプルピークの差が開きやすい。

RMS 窓付き二乗平均

一定時間の二乗平均の平方根。エネルギーに比例するので VU より理屈がはっきりしていますが、周波数の重み付けがありません。低域が多い音ほど「数字の割に小さく聞こえる」ことになります。

窓
50 / 300 / 1000 / 3000 ms（矩形窓）
サイン波
ピークより −3.01 dB。AES-17表記では +3.01 dB 補正してピークと一致させる
使いどころ：コンプの検出方式（Pro-C 3 や Unisum の RMS 窓）を理解するための基準。300 ms 前後はVUに近い挙動、50 ms はトランジェントにかなり反応します。

PPM IEC 60268-10 Type II 系の近似

Quasi-Peak メーター。数 ms のアタック積分で極端に短いトランジェントは少し低く読み、ゆっくり戻るので目で追いやすい。放送のレベル管理で長く使われてきました。

アタック
τ = 4.8 ms（10 ms バーストで約 −4 dB）
リターン
24 dB / 2.8 s（≈ 8.6 dB/s）
表示
ここではdBFSで表示。実機BBC型は 1〜7 の目盛り
使いどころ：ボーカルやセリフのピーク管理。サンプルピークほど神経質でなく、VUほど鈍くない中間の視点として、ブレスやサ行の飛び出しを見るのに向きます。

LUFS ITU-R BS.1770 / EBU R128

K特性（高域シェルフ+4 dB、38 Hz付近のハイパス）で聴感に寄せた二乗平均を、チャンネル合算して測ります。数値の差は LU。Integrated はゲートで無音や小音量部分を除外します。

Momentary
400 ms 窓
Short-term
3 s 窓
Integrated
400 ms ブロック（75%重複）、絶対ゲート −70 LUFS、相対ゲート −10 LU
LRA
Short-termの10〜95パーセンタイル幅（相対ゲート −20 LU、Tech 3342）
目安
Spotify / YouTube −14、Apple Music −16、放送 −23 LUFS
使いどころ：配信時の正規化でどれだけ下げられるかの予測、曲間・アルバム内の音量感の統一。−14 を超えても配信側で下げられるだけなので、PLR（ダイナミクスの余白）とのトレードオフで決める。

LRA EBU Tech 3342 · LU

曲の中でセクションごとの音量感がどれだけ動くかを示す値。Short-term（3 s）の分布の 10〜95 パーセンタイル幅です。フェードアウトや一瞬のキメは上下のパーセンタイルで除外されます。

入力
Short-term loudness（3 s 窓）の全履歴
ゲート
絶対 −70 LUFS、相対 −20 LU（Integratedの −10 LU より緩い）
動かすもの
アレンジ、オートメーション、セクション構成
動かないもの
速いアタックのコンプ（3 s 窓には見えない）
傾向
EDM・メインストリーム 3〜6 / インディー 5〜9 / ドリームポップ・ポストロック 8〜15 LU
使いどころ：バスやマスターの処理でAメロとサビの差が均されていないかの確認。マスターリミッターを深くしても LRA がほぼ変わらず、マスターバスで長いリリースのコンプを深くかけると下がる、という違いで処理の効き方を切り分けられます。

PLR Peak to Loudness Ratio · LU

Max True Peak − Integrated。曲全体で見たピークと平均音量の差で、トランジェントがどれだけ残っているかを示します。リミッターで稼いだ音圧の分だけ、ほぼ dB 単位で減ります。

例
−1 dBTP / −8 LUFS → 7 LU、−1 dBTP / −13 LUFS → 12 LU
正規化後
−14 LUFSに揃えると、ピークは −14 + PLR dBTP になる
傾向
6〜8 詰めたマスター / 9〜11 モダンポップ / 12〜14 インディー / 15以上 アコースティック
注意
曲中の最大ピーク1発で決まる。外れ値のピークがあると大きく出る
使いどころ：配信での聴こえ方の予測。−8 LUFS のマスターは −14 に下げられてピークが −7 dBTP 付近まで落ち、−13 LUFS / PLR 12 のマスターよりアタックが引っ込みます。PLR が良すぎるときは Max True Peak の位置を確認し、そこだけクリップゲインで抑えます。
