02 / TIME DOMAIN

Waveform · 横軸：時間 / 縦軸：振幅

03 / ENERGY DECAY CURVE

Schroeder Integration · 相対レベル（dB）

04 / MEASUREMENTS

Duration—seconds
Peak position—milliseconds
EDT estimate—seconds
T20 estimate—seconds

EDT：0〜−10 dBの傾斜から60 dB相当へ外挿。T20：−5〜−25 dBの傾斜から外挿。短いIRやノイズの多いIRでは推定値が不安定になります。

05 / ALGORITHM REVERB

簡易Schroederモデル。パラメーターを変更してIRの減衰・密度の変化を確認できます。

06 / A/B LISTENING

同じ短いテスト信号をReference IRとAlgorithm IRで畳み込み、残響を比較します。

注：この試作版は学習・方向性確認用です。自動マッチングや厳密な音響測定はまだ実装していません。
Reverb Lab prototype · 解析・音声生成はローカルブラウザ内で処理します。IRは直接音の位置合わせやノイズ除去を行わずに解析するため、測定値は参考値です。
